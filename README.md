# Ocasio Disable Comments Globally

> Lightweight WordPress plugin to completely disable and remove comments, trackbacks, and pingbacks site-wide.

## Overview

For websites that don't need blog comments, **Ocasio Disable Comments Globally** closes the entire comment system across posts, pages, and media, removing admin clutter and eliminating comment spam.

## Features

* **Close All Comments:** Automatically closes comments across posts, pages, and custom post types.
* **Remove Admin Menus:** Hides the Comments menu and discussion screens from your WordPress admin.
* **Block Trackbacks & Pingbacks:** Prevents pingbacks and bot spam from hitting your database.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JS loaded on public pages.
* **Instant Dashboard Toggle:** Manage and toggle the switch directly from the **Ocasio Plugins** dashboard.

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `ocasio-disable-comments-globally.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **Ocasio Plugins -> Dashboard** menu.
