Completely disables and removes the WordPress comment system across all posts, pages, and media files.

== Description ==

Most modern business websites, marketing landing pages, and affiliate hubs have zero need for blog comments. Managing comment spam, bot pingbacks, and database bloat is a massive distraction when you don't use comments.

Ocasio Disable Comments Globally closes the comment system completely across your entire WordPress site. It closes comment forms on all existing and future posts, blocks trackbacks and pingbacks, hides existing comments, and removes the Comments menu from your admin dashboard.

You get a clean, quiet dashboard and faster page load speeds with zero configuration.

= Features =

* **Closes All Comment Forms:** Disables comments on posts, pages, and custom post types.
* **Hides Admin Clutter:** Removes the Comments menu and discussion screens from your WordPress dashboard.
* **Blocks Pingbacks & Trackbacks:** Stops bot trackbacks from hitting your server.
* **Hides Existing Comments:** Keeps your front-end design clean without deleting comment history in your database.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JavaScript.
* **Instant Dashboard Switch:** Turn the feature on or off in one click directly from the Ocasio Plugins dashboard.

== Installation ==

1. Upload the `ocasio-disable-comments-globally` folder to your `/wp-content/plugins/` directory, or install it directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to **Ocasio Plugins -> Dashboard** in your sidebar to toggle your settings.

== Frequently Asked Questions ==

= Does this delete my existing comments from the database? =
No. It only hides them and closes commenting forms. If you ever deactivate the plugin, your previous comments remain safe in your database.

= Will this speed up my site? =
Yes. Removing comment scripts, gravatar requests, and database queries speeds up page load times across your site.
